## Agent skills

### Issue tracker

Issues and specs live as local Markdown under `.scratch/<feature>/`.
Before publishing or fetching work, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles.
Before triaging work, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Before exploring domain concepts or decisions, read `docs/agents/domain.md`.
